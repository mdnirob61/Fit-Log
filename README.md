## 📌 About The Project

**FitLog** is a beginner-friendly workout tracking website built with
Next.js, React, TypeScript, and Tailwind CSS.

The website allows users to explore different workouts and see useful
information about each workout.

Users can also save workouts and create their own personal workout plan.

---

## ✨ Features

| Feature                  | Description                                                                                     |
| ------------------------ | ----------------------------------------------------------------------------------------------- |
| 🏋️ **Explore Workouts** | Browse different workouts with their muscle groups, difficulty, duration, and rating.           |
| 📋 **Workout Details**   | View detailed information about a workout, including description, sets, reps, and instructions. |
| ➕ **Create My Plan**     | Add workouts to your personal workout plan.                                                     |
| ❤️ **Save Workouts**     | Save workouts that you want to use later.                                                       |
| 🗂️ **Manage Workouts**  | View and manage your saved workouts and personal workout plan.                                  |

## 🎯 Project Goal

The main goal of **FitLog** is to create a simple workout website that helps
users discover workouts and manage their personal workout plans.

The basic flow of the website is:

**Explore → View Details → Save → Create My Plan**
